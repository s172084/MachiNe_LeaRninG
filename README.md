# Project Overview

This project focused on applying machine learning techniques to the Diamonds dataset from the `ggplot2` library in R. The project involved both regression and classification tasks, with the machine learning models and data analysis implemented using the R programming language. Data exploration and visualisations were created using `ggplot2` to investigate patterns and relationships within the dataset.

A range of R libraries were used throughout the analysis, including `tidyverse`, `magrittr`, `forcats`, `patchwork`, `ggplot2`, `glmnet`, `knitr`, `kableExtra`, `rpart`, `caret`, `tidyr`, `neuralnet`, and `broom`. These packages supported data manipulation, visualisation, model development, cross-validation, decision trees, neural networks, and presenting analytical results. Model performance was evaluated using the Root Mean Squared Error (RMSE) metric through `ModelMetrics::rmse`.

My contribution focused on the regression component of the project, where I developed and evaluated regression models to predict diamond-related outcomes. My teammate was responsible for the classification component. This project demonstrates experience with machine learning workflows, statistical evaluation, data visualisation, and collaborative development using R.
